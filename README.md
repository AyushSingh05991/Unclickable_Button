# Interactive Question Page

This project is a fun interactive question page where the user is presented with multiple questions. The page includes two buttons for each question: "Yes" and "No". The "No" button moves to a random position when hovered over, while the "Yes" button can be clicked to proceed to the next question.

## Features

- A series of questions that change dynamically when "Yes" is clicked.
- A "No" button that moves randomly on hover, making it impossible to click.
- A modal that provides initial instructions to the user.
- Responsive and modern design with a playful user interaction.

## Instructions

1. **Rule**: Always click "Yes" to proceed.
2. The "No" button will avoid clicks by moving to random positions.
3. Clicking "Yes" will change the question to the next one in the series.
